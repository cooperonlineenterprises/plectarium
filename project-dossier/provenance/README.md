# Provenance

Record every consequential source with:

- stable source ID;
- location and version;
- source role;
- observation date;
- intended use;
- limitations;
- freshness rule;
- sensitivity.

Current sources are recorded in `machine-readable/sources.json`. Project
Blueprint establishes structure only. The current operator invocation supplies
task-scoped foundation authority; its saved workspace copy supplies provenance
only. The family packet supplies family product contracts and is pinned to full
closure commit plus packet and consumed-contract digests.
