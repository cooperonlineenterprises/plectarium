# Implementation Authority Boundary

The current repository-foundation prompt authorizes specification and bounded
publication, not product implementation. Packet task status cannot change that.

Future implementation authority must identify exact task(s), repository paths,
permitted effects, credentials/data boundaries, validation, external actions,
and stop conditions. Lower-level agents, skills, workflows, test fixtures,
capability plans, and results may narrow but never expand it.

Capability conclusions cannot authorize Plectarium actions. Plectarium
approvals authorize only the exact plan/effects within their external policy
channel and do not transfer to project implementation work.
