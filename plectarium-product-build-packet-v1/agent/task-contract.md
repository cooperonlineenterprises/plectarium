# Task Contract

Every task declares ID, status, workstream, dependencies, objective, product
claim, authoritative inputs, permitted surface, forbidden changes, outputs,
acceptance criteria, tests, evidence, handoff, and risks.

A task is ready only when dependencies, authority, inputs, and validation plan
are satisfied. Completion requires fresh evidence, review, limitations,
external effects, and an unambiguous next state. Passing tests prove only their
named claim and subject.
