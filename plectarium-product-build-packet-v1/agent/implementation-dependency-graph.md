# Implementation Dependency Graph

```text
S0 authority/source lock
  → S1 foundational contracts
    → S2 Minimum Complete Control Plane
      → S3 experience and modes
        → S4 hardening
          → S5 mature v1
```

Parallel work is safe only within a stage after shared schemas and ownership
are fixed. The Minimum Complete Control Plane proves contract integration, not
product maturity. No stage status creates implementation authority.
