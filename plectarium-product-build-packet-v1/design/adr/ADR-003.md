# ADR-003: Modular control plane and process-isolated capabilities

**Status:** Accepted; shared runtime deferred  
**Decisions:** PLEC-006, PLEC-007, PLEC-019

Start with a modular control-plane product boundary. Capabilities execute via
their canonical CLIs or exact OCI artifacts outside the control-plane process.
Modules become deployables only when measured security, scale, failure,
ownership, or operational needs justify the cost.

A service per capability and a universal plugin/runtime layer are rejected.
The family SDK threshold remains implementation-backed and unmet by document similarity.
